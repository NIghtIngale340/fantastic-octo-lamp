## Description

Someone has been using the Bitcoin blockchain to store secret messages.
Investigators believe the blockchain contains a trail leading to the suspect's wallet address, but there is one problem:
We don't have the wallet address.
The only evidence recovered is a rather grumpy cat picture.
Somewhere within the image is the clue needed to begin the investigation.
Follow the trail through the Bitcoin blockchain, locate the wallet address, and recover the hidden flag.

🎯 Mission
Analyze the provided image and use the information you discover to locate the Bitcoin wallet associated with the hidden messages.
Investigate the wallet's blockchain transactions and recover the secret flag.
You are looking for a traditional flag{}.

🛠️ Suggested Tools
ExifTool
Strings
Binwalk
Bitcoin blockchain explorer
Bitcoin transaction decoder
Python
Hexadecimal/ASCII conversion tools

🚩 Flag Format
Submit the recovered flag using the traditional format:
pcgCTF{theflaghere...}
