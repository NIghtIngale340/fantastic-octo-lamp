## Description

The director of a company suspects that two employees are secretly communicating with each other.
Their messages appear completely ordinary and remain on-topic. Nothing immediately suggests that a secret conversation is taking place.
However, investigators believe the employees are using a mathematical sequence to conceal their real message.
A document has been recovered. Somewhere within it are subtle clues pointing toward the method being used.

🎯 Mission
Analyze the document and identify the mathematical sequence being used to conceal the communication.
Use the discovered sequence to recover the two-word secret message.
The first word is FLAG.

🛠️ Suggested Tools
Text editor
Python
Spreadsheet
Mathematical sequence analysis
Manual pattern analysis

🚩 Flag Format
The recovered message consists of two words.
Submit the complete message using the traditional flag format:

pcgCTF{flaghere..........}
