## How to review these drafts

- **Verified** identifies a saved scoreboard state or an independently checked OverTheWire authentication, as stated. It does not imply every historical command was rerun.
- **Needs Flag Verification** identifies an evidence-supported answer whose PCGCTF submission is unconfirmed. Some exact spellings are accepted according to the teammate’s report; that attribution is explicit.
- **Partial / unresolved** drafts include the evidence examined, bounded independent attempts, the missing dependency and concrete next steps. Historical solves can still have partial documentation when their original artifacts or accepted string are missing.
- Recorded outputs, newly reproduced checks, teammate-reported outputs and future command recipes are labeled separately. No screenshots or successful site responses were invented.
- Natas runtime passwords are redacted in these publication-facing drafts and the copied snapshot. The original private working records remain outside this collection.
- Some local evidence links lead back to the preserved PCGCTF archive. Publish only reviewed evidence; do not upload the entire private archive.
