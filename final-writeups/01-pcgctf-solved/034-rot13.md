## Initial analysis

ROT13 is a Caesar rotation by half the 26-letter alphabet. The title supplies the method and the short phrase preserves spaces. Because rotating twice returns the original text, the decoder can be checked without needing an external expected answer.

## Step-by-step solution

### 1. Rotate all alphabetic characters by thirteen

Python’s `rot_13` codec rotates letters while preserving spaces. The assertion applies the same transform to the result and checks the original ciphertext, providing a simple reversibility check.

```sh
python - <<'PY'
import codecs
s='synt vf pbby'
p=codecs.decode(s,'rot_13')
assert codecs.decode(p,'rot_13')==s
print(p)
PY
```
