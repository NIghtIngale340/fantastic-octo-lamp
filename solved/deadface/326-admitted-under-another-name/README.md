## Description

DEADFACE dumped the patient registry from Aurora Health. Buried in it is one high-profile patient who checked in under a fake name — the staff quietly flagged the record as a VIP. Access the database, find that patient, and report their real Medical Record Number (MRN).

Use the provided MSSQL shell access to query the patients table.

Submit the flag as deadface{MRN}. Example: deadface{AH-1234567}.
