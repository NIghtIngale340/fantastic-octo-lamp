## Description

At first glance, this appears to be nothing more than an archive filled with pictures of happy turtles.
But one of them doesn't belong.
Somewhere among the collection is a turtle that isn't quite as happy as the others. The original image may also hold an important clue about what has been changed.
Find the unusual image and uncover what has been hidden.
You are looking for a traditional flag{}.

🎯 Mission
Investigate the collection of turtle images, identify the unusual image, and recover the hidden flag.
Pay particular attention to the dimensions and visual structure of the images.

🛠️ Suggested Tools
file
ImageMagick
ExifTool
Python/PIL
Image viewer
Steganography analysis tools
🚩 Flag Format

Submit the recovered flag using the traditional format:

pcgCTF{theflaghere}
