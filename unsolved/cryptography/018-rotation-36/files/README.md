# Beginner — Caesar (Alphanumeric)

**Story:** A field memo was encoded using a Caesar shift—but the operator used an alphabet of `A–Z` and `0–9`.

**Task:** Decrypt `cipher.txt`.

**Alphabet:** `A–Z` followed by `0–9` (total 36 chars). Non-alphanumerics are left as-is.

**Hint:** Case-insensitive; think modulo 36.

**Output:** Find the flag in the recovered message.
