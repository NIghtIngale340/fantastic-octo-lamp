## Description

A network capture was recovered from a system suspected of conducting an unauthorized cryptocurrency transaction.

Your mission is to analyze the provided PCAP file and trace the network communication to identify the Bitcoin wallet address involved in the transaction.
🎯 Mission

What is the Bitcoin wallet address found in the PCAP file?
🚩 Flag Format
Example format:pcgCTF{b1tcoin.............}

Analyst Note: The objective is to identify the wallet address from the network evidence—not to interact with or send funds to the address.
